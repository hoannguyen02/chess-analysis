# Practice book topic order

Each row is one book. Read the tactic list in order within that level. The same
topic can recur with positions that meet a different level's requirements.

IDs in backticks come from `themes[].id` in the
[practice map](../scripts/fixtures/tactics-index/tactics-map.json).
A **†** beside an ID means its `dedicatedPage` is empty. For example, Tấn công đôi
(`fork`) has its own route, while Chiếu hết Blind Swine (`blindSwineMate`†)
belongs under Chiếu hết bằng hai Xe. Some marked entries serve as subtopics,
review filters, rule references or practice links. The marker tracks dedicated
pages, and chapter availability depends on reviewed positions at that level.
