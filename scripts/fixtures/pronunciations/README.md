# Pronunciation parser fixtures

Extracted pronunciation sections from the English entries for read, start,
check, complete, arrange, match, choose, look, say, write, name, one, August, food, and then.
Retrieved 2026-09-18 from https://en.wiktionary.org/w/rest.php/v1/page/WORD/html.
Wiktionary contributors; CC BY-SA 4.0 https://creativecommons.org/licenses/by-sa/4.0/.
Changes: only pronunciation sections retained; audio, tables and styles removed.
Source and attribution for each: https://en.wiktionary.org/wiki/WORD#English
(replace WORD with the fixture filename without .html).

These fixtures test actual dictionary markup, accent labels, alternate senses,
and shared IPA. They are data, not executable markup in the application.
